# Mess Management System

The Mess Management System is a web application for running the day-to-day meal service at a college. It gives administrators one place to manage student accounts, publish a weekly menu, post notices, mark mess-closed dates, and review attendance reports. Attendance is recorded separately for Morning, Afternoon, and Night meals, with search, bulk marking, and a short editing window to make daily updates practical. Students have their own dashboard where they can see today’s menu and attendance status, browse the weekly menu, check meal-by-meal attendance on a monthly calendar, read notices, and manage their profile.

The application uses **Next.js App Router** and **React** for its pages and server-side API routes, with **Tailwind CSS** for the responsive interface. **MongoDB** stores users, menus, attendance, notices, and holidays, accessed through **Mongoose** models. **NextAuth** provides credential-based sign-in and role-aware access for admin and student areas. Shared **Zod** schemas validate data at the API boundary and in forms, while **React Hook Form** manages form state. Meal windows use the Asia/Kolkata timezone: Morning 07:00–10:00, Afternoon 12:00–15:00, and Night 19:30–22:30. The project is designed to run locally with environment-based configuration and can be deployed to Vercel with a production MongoDB connection.
